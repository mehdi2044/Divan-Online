# نمونهٔ سه‌صدایی فصل اول · elevenlabs.io

این پوشه نمونهٔ کوتاه، غیرتجاریِ فصل اول است؛ کتاب صوتی کامل نیست. چهار فایل با سه صدای متفاوت تولید شده‌اند. نه کلید API در کتاب وجود دارد و نه پخش به حساب یا نشانی موقت نیاز دارد. حقوق استفادهٔ تجاری از صداها در این تغییر احراز نشده است.

متن قابل‌استفادهٔ مجدد: `assets/chapter1/chapter1.json`. هر صحنه شامل قطعه‌های متنی و هر قطعه شامل یک یا چند بخش گفتاری با شناسهٔ ثابت، نقش و متن است. در تولید، اگر `spokenText` وجود دارد از آن استفاده شود. نگاشت شناسه به فایل محلی در `manifest.json` است. ترتیب پخش از ترتیب متن می‌آید، نه ترتیب نام فایل‌ها. فایل‌های کامل پس از تأیید هزینه و بازبینی شنیداری قابل افزودن‌اند. لازم نیست پخش‌کننده برای فصل کامل بازنویسی شود.
